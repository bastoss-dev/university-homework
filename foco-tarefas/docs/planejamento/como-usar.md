# Como foi usado o gerenciamento de projetos

**Ferramenta online:** GitHub Issues com uma visualização de quadro em Markdown no repositório. Os 13 itens têm responsável (Yuri Fernandes Bastos), etapa, status e link para histórico do registro.

**Colunas:** A fazer, Em andamento, Em testes e Concluído.

**Estado atual:** P01–P12 concluídos; P13 (conferência e envio ao Canvas) em A fazer. Uma issue pode ser reaberta para ajustes e movimentada de volta para Em andamento/Em testes. A execução é responsabilidade do único integrante identificado.
